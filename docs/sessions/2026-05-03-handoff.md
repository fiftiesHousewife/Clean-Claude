## Decisions worth preserving (don't relitigate)

1. **`@Override` is the right axis for "skip contract-mandated
   signatures"** (used by F2). Did NOT fold into
   `BoilerplateMethodSkip.isContractMethod` because other recipes (e.g.
   C3 mumbling) legitimately fire on `@Override` methods. Lives as
   `BoilerplateMethodSkip.isOverride` and is called explicitly from
   `OutputArgumentRecipe`.
2. **G33 fires on repetition, not on every `±1`**. The book's smell is
   the SAME boundary expression appearing twice. Single-use
   `items.size() - 1` / `lastIndexOf('/') + 1` is idiomatic.
3. **G34 = banner shape only**. Per `HEURISTICS.md`, G34 is `// ===
   section ===` style markers. Long explanatory comments are
   documentation, not banners. Threshold raised from 1 → 2.
4. **G31 same-receiver-and-method key, via printTrimmed**.
   `Expression.toString()` includes AST internals — two textually
   identical chains still produced different keys. Use
   `select.printTrimmed(getCursor())` for a stable source-form key.
5. **G35 trivial floor = 4**. `2`/`3`/`4` are nearly always indices.
   Real magic numbers (60s, 100%, 120 cols, 1000ms) are still caught.
6. **N1 skips suffix when supertype shares it**. `ReportHandler
   implements HttpHandler` is contract-mandated — the user can't rename
   without breaking the supertype.
7. **Ch7.2 doesn't count `Objects.requireNonNull`**. It's the
   recommended fail-fast pattern, not a smell.
8. **C2 needs mixed-case + length ≥ 3**. Filters acronyms (`MCP`,
   `HTML`, `URL`) without needing a project-wide class index.

## Known recipe limitations to keep in mind

1. **`MagicStringRecipe` / G5 short-format filter** is permissive: it
   only filters strings that have ZERO letters or digits AND length ≤
   5. So `"%.4f"` (has `4` and `f`) still fires. Acceptable for now —
   `"%.4f"` arguably IS a real magic format string. Tighten only if
   real users complain.
2. **`G31 TemporalCouplingRecipe` distinct-call key** uses
   `printTrimmed(getCursor())`. If the same chain has different
   whitespace formatting in two places, the keys won't match and they
   register as distinct. In practice formatters normalise this; not
   worth chasing unless we see false positives.
3. **`G33 BoundaryConditionRecipe` per-method state** uses a
   non-thread-safe `HashMap` field on the visitor. OpenRewrite visitors
   are single-threaded per file but if that ever changes, the recipe
   needs synchronisation.
4. **`C2 ObsoleteCommentRecipe` `looksLikeAJavaIdentifier`** rejects
   tokens shorter than 3 characters or all-uppercase. So `Map`, `id`
   are rejected too. Acceptable — short tokens are too noisy as
   prose-vs-code signals.

        ├─ GET  /                  serves findings.html fresh from disk

        ├─ POST /api/apply-changes ApplyChangesRequest → ChangeApplier
        │                            ├─ BuildScriptEditor (line-based)
        │                            ├─ SourceFileEditor  (JavaParser)
        │                            └─ [P1] RefactoringApplier
